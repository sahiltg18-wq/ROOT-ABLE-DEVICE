## Deploy to GitHub Pages

1. **Create a new repository** on GitHub called `infinity-x-devices`

2. **Clone the repo locally:**
   ```bash
   git clone https://github.com/yourusername/infinity-x-devices.git
   cd infinity-x-devices
   ```

3. **Copy `index.html` to the repo root**

4. **Commit and push:**
   ```bash
   git add index.html
   git commit -m "Initial commit: Infinity X device listing"
   git push origin main
   ```

5. **Enable GitHub Pages:**
   - Go to **Settings → Pages**
   - Under "Build and deployment," select:
     - **Source:** `Deploy from a branch`
     - **Branch:** `main` / `root`
   - Save

6. **Done!** Your site is live at:
   ```
   https://yourusername.github.io/infinity-x-devices
   ```
